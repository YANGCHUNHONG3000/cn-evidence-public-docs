64 individual V3 data tools are deployed. MCP tools/list currently returns 68 entries: 64 data tools, 3 older tools, and one free schema helper. The live catalog is authoritative for current tools, schemas and prices. Do not treat the count as 104 available tools.

Each new V3 tool call costs 0.011 USDC and makes one upstream call. A funded Base USDC wallet and x402-compatible client are required to pay. The tools passed server upstream smoke checks, including empty and statistical results. The new 64 have not completed real-wallet payment, settlement and delivery acceptance; no complete paid-flow claim is made here.

HTTP

POST https://api.cnevidence.com/x402/cn/tools/<v3_tool_name> with JSON body:

{"arguments":{"company_id":"24-lowercase-hex-id"}}

Illustrative shape only, not a runnable request. Use the exact argument schema shown in the live catalog/OpenAPI and satisfy the x402 payment challenge. Required arguments vary by tool.

MCP

Data tools are named cn_data_<v3_tool_name>. A tools/call request nests the tool arguments as follows:

{"name":"cn_data_v3_company_detail","arguments":{"arguments":{"company_name":"精确中文企业法定名称"}}}

Company detail accepts the exact Chinese legal company name or an upstream company_id. Other company tools require that returned company_id. Use get_cn_data_tool_schema with tool_name="v3_company_detail" for a free local schema and price lookup. It does not query upstream data. The live catalog is the source of truth.

Identity and paging limits

  • Company detail accepts an exact company_name or company_id. Other company tools require the 24-character lowercase hexadecimal company_id obtained from company detail.
  • Record detail tools require a record_id obtained from the matching list tool. A detail call does not perform a hidden lookup. Each paid tool call is separate.
  • Paged V3 list tools return only the first page, up to five items. There is no automatic pagination, history query or retry. Array or statistical tools may have different shapes; check their live schema and description.
  • An empty response is not proof of no risk, nonexistence, complete history or nationwide coverage. Statistical and filter summaries are not underlying record details.

The retained legacy Basic and Full packages remain separate: 0.032 and 0.093 USDC respectively, covering 3 and 9 modules, with lists limited to the first page of up to 10. Their package descriptions apply only to those legacy packages.

The retired local Shenzhen/Beijing dataset and free entity resolution are not current services. Free identity preflight checks input format only. Native MPP and the old the402 flow remain paused. No data-field or commercial redistribution rights are asserted by this guide.
