后续可做的人工核查

  1. 使用权威主体信息确认目标法律实体；本样例已隐藏身份信息。
  2. 核对登记变更与行政许可原始记录；如决策需要完整历史，应继续检查后续页。
  3. 结合当前原始凭证和具体交易背景，复核股东及纳税信用记录。
  4. 另行检查受益所有权、制裁、工厂能力、收款账户归属及其他重大风险。

以上是依据所示覆盖范围提出的审查步骤，不是对被隐去企业的新发现。
