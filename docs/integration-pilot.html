Standard first / 标准版试点范围

0.29 USDC per successful fixed-scope Standard order. Ten Jinghai-first check dimensions: registration, operating exceptions, administrative penalties, shareholders, registration changes, licenses, tax credit, tax arrears, court notices and judgments. Jinghai lists use their first page, up to five records. Only a license connection/call failure or open circuit permits one QCC administrative-license replacement, up to 100 records with incomplete coverage and separate source attribution.

固定十项、优先鲸海，提供 JSON 和中英文 HTML；鲸海每个列表仅首页、最多五条。仅许可接口连接/调用失败或已熔断时，补一次企查查行政许可、最多100条，保留原失败与新来源，不代表完整覆盖。不自动翻页、不含人工复核。需要企业中文登记全称，品牌名或英文译名不足以直接查询。

All contracted checks must validate and the report must be stored before settlement. Errors or missing required checks prevent settlement. No-record responses do not establish no risk. Availability depends on current provider balance and runtime checks.

Enhanced (0.59 USDC) adds exactly one QCC qualifications lookup to Standard, including its conditional license replacement: at most two QCC calls. QCC-only (0.03 USDC) supplies qualifications JSON, not analysis. Screening reports also support get_china_company_report through the MCP facade over the same HTTP x402 checkout; QCC-only qualifications remain HTTP-only. Free MCP options and recovery tools are available. The new MCP report path has not had a funded end-to-end acceptance. Exact scope and version-specific acceptance.

Standard has a historical owner-funded HTTP acceptance sample. The current license-fallback Standard and Enhanced contracts have not had a fresh funded purchase; neither the historical sample nor an unsigned quote certifies their paid path. No customer-success claim is implied.

Integration outline / 接入概要

  1. Read the free live catalog. Check Standard availability and fetch the current contract.
  2. Prepare POST /x402/cn/products/screening-standard-v1 with the exact company name and current contract. An unsigned valid request provides payment requirements; it does not purchase provider data.
  3. Privately generate and save a fresh recovery token before a funded request. A compatible buyer signs only after explicit spending approval; ordinary MCP clients do not pay automatically.
  4. After uncertain payment or timeout, recover/reconcile the original order, never automatically repay. Original report recovery lasts 24 hours and makes no new provider query.
{
  "arguments": {"company_name": "<exact Chinese registered name>"},
  "contract": "<current contract from live catalog>"
}

This is the request outline. Use the dedicated Standard client below for the guarded workflow. Product and recovery reference. The separate company-detail buyer guide does not implement every product.

Runnable Standard client / 可运行的标准版示例

Download standard-client.mjs Read the source before running it. Requires Node 20+. This example purchases only Standard (0.29 USDC); it cannot buy Enhanced, QCC-only or individual data tools.

Verification boundary: this helper has offline workflow tests, including license-fallback validation, and a live unsigned preview on 2026-10-13. It has not had a fresh funded-client acceptance. The historical internal Standard purchase used a different acceptance script; it is not proof of this helper's funded path. No end-customer purchase is claimed.

1. Preview — free, no wallet / 免费预检

Save the client in a private working folder. Replace the example below with the exact Chinese legal name. Preview reads the catalog and an unsigned quote only: no upstream business query, wallet or SDK packages. It does not verify company existence, provider credit balance or eventual delivery.

node standard-client.mjs preview --company "企业中文登记全称"

Review the returned contract, price and scope. Do not reuse a contract copied from an old email or screenshot. A changed contract stops the purchase until you review it again.

2. Optional purchase — one attempt / 明确批准后仅尝试一次

Only after deciding to spend 0.29 USDC: install the pinned buyer packages and configure CN_EVIDENCE_PRIVATE_KEY through your trusted local secret manager. Never send us a key or put it in command arguments, screenshots, source control or a shared terminal log. Use a dedicated low-balance buyer wallet; this page does not ask you to fund it.

npm install --save-exact @x402/core@2.25.0 @x402/evm@2.25.0 viem@2.56.3
node standard-client.mjs buy --company "企业中文登记全称" --approve-contract HASH_FROM_YOUR_PREVIEW --max-usdc 0.29 --state order-001.private.json --out report-001.private.json

The client checks the exact product, Base USDC, recipient and amount. It saves an exclusive recovery-state file before accessing the wallet, signs once and sends one funded request. It never retries payment, paginates or increases the budget automatically. The server may perform only the license replacement explicitly included in the approved contract; the client validates its separate source and limits. Existing order/output files stop a new purchase.

购买需明确提供最新合约哈希和 0.29 的金额批准。状态文件、订单标记和报告均须保存在私有、非同步目录；Windows 用户需要自行限制目录 ACL，文件创建参数不等于完整的 Windows 访问保护。

3. Recover the same report / 免费领取原报告

Keep order-001.private.json and its .attempt.json sidecar together. They identify the original order; the state includes a private recovery token. After a timeout or uncertain response, do not delete these files or choose a new state filename to buy again. The uncertain exit code is 2. Recover within 24 hours to a new output filename, without a wallet or another provider query:

node standard-client.mjs recover --state order-001.private.json --out recovered-001.private.json
node standard-client.mjs recover --state order-001.private.json --out report-001.en.private.html --format en
node standard-client.mjs recover --state order-001.private.json --out report-001.zh.private.html --format zh-CN

HTML recovery first validates the original JSON order, then requests the chosen HTML format; neither request pays again. JSON identity, checklist and scope are checked against the saved original contract, not a new product version. A settlement header is not independent chain verification. If recovery says pending, unavailable or expired, retain the files and reconcile the original order; do not automatically repay. If signing stopped before an attempt sidecar existed, inspect that local failure first rather than assuming a payment happened.

免费恢复只领取已有原单，不补查缺失数据、不延长 24 小时保留期。报告只是固定十项初筛：零记录不等于无风险，首页不等于完整覆盖，不包含人工复核。

For your own diagnostic probes, add --internal-test to label them as internal traffic; never count them as buyer demand. Offline workflow tests.

What counts as a useful pilot / 怎么验收

  • The legal entity and requested scope match the intended supplier.
  • The report is delivered, readable and useful for the stated review task; gaps and first-page limits remain visible.
  • For a paid pilot, the agreed amount, settlement and original-order recovery reconcile without duplicate payment.
  • Record buyer feedback and willingness to use it again. An automated acknowledgement, listing or platform test is not customer demand.

最终看是否解决了真实问题、是否愿意继续使用；发送、回复、试用、付款、复购分别统计。
