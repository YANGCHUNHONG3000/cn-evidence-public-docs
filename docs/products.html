This fixed package covers ten named Jinghai checks: company details, operating exceptions, administrative penalties, shareholders, registration changes, licenses, tax credit, tax arrears, court hearing notices and judgments. Each list uses only its first provider page and returns at most five items. There is no automatic pagination or retry.

固定包含鲸海十项查询：主体登记、经营异常、行政处罚、股东、登记变更、行政许可、纳税信用、欠税、开庭公告和裁判文书。每个列表仅取服务商首页，最多五条；不自动翻页或重试。

Settlement occurs only after all ten contracted queries validate and the report has been stored. The report is available as JSON or Chinese- or English-language HTML and can be recovered without a new provider query. This is a screening report, not complete due diligence, a safety verdict, or a guarantee that the records are exhaustive. An empty result is not proof that no risk exists.

Never place this private token in a URL. After a timeout or uncertain payment, check the existing order; do not automatically pay again. The new product route is HTTP x402 only, not a new MCP tool.
