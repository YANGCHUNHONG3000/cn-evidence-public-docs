使用场景 · 政府采购与中标证据

查供应商中标记录，也保留能回溯的证据

采购公告中的中标信息，可以帮助了解供应商曾参与哪些公共采购活动。但中标记录回答的是一个已记录事件，不是完整的履约表现。

查看 OpenAPI连接 Remote MCP

Remote MCP 是供客户端配置的 Streamable HTTP 端点，不是网页查询表单。

中标证据能说明什么，不能说明什么

政府采购记录中的公告编号、项目编号、采购方、日期和金额，在原始来源确有这些字段时，可为供应商历史筛查提供线索。字段缺失时，不应由智能体补出“看起来合理”的项目详情。

中标 ≠ 已证明履约成功。中标证据不能单独证明交付、验收、付款完成或没有争议。采购尽调需要这些结论时，应另行取得对应材料。

  1. 先确认供应商主体。采购公告里的同名企业，不应在缺少关联依据时自动归到目标公司。
  2. 先看摘要、linkage 和 dataset_coverage。当前文档中的采购来源为北京中标数据，并不是全国所有招投标记录。
  3. 需要留档时选择 Full，保存 content_id、公告或标段编号，以及返回时存在的 source_files。这些证据来源字段帮助你回到原始材料。

可追溯不等于每行都有公开直达链接。数据集定位与单条记录定位各有作用，应保留返回内容，不把供应商中标次数改写成“已验证履约能力”。
