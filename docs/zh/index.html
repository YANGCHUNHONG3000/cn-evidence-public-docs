来源有地域，结论有边界

当前公开契约描述的来源包括深圳企业／统一社会信用代码、经营异常和行政处罚数据集，以及北京政府采购中标数据。请保留每次响应的 dataset_coverage、linkage 和 coverage_notes。

  • 企业身份：配置范围内的法定名称与 USCC 证据，不是全国完整工商库。
  • 政府采购：中标与采购轨迹，不代表合同交付、验收或履约已核实。
  • 监管与行政处罚：历史记录和当前数据集可用的处罚证据；确认数为 0 不代表全国无处罚，也不是合规认证。
  • 避免同名误绑：没有足够关联依据，不把同名采购或处罚记录挂到某家公司。
  • 区分历史与当前：经营异常流程记录不自动等于当前经营异常；保留 UNKNOWN。查询时间不等于所有上游记录的更新时间。

Full 比 Basic 多了什么？

两档都包含筛查事实及数据集范围。Full 还可以给出事实背后的证据行，每行包含 type、source、dataset、checked_at，以及至少一个有效的 dataset_id 或 content_id。有公告编号、原始记录或来源文件定位时，应一并保留。

免费 Full 样例以 evidence_limit=2 展示总数 6 中的 2 条，truncated=true：一条采购中标、一条监管历史。其中 NOT_ENTERED 不表示当前经营异常，也不是处罚结论。

所有样例均为静态说明，标记 example:true 和 not_live_query:true。它们解释接口，不是实时企业尽调事实。

从不付款的请求开始

规范 API：cn-evidence-agent402-public.mikeyang7789.workers.dev

curl -i -X POST \
  'https://cn-evidence-agent402-public.mikeyang7789.workers.dev/x402/cn/supplier/evidence' \
  -H 'Content-Type: application/json' \
  --data '{"uscc":"9144030033518485XF","include_evidence":true,"evidence_limit":2}'

这条普通 curl 不带支付签名，不会付款。合法的未签名付费请求返回 HTTP 402；真正购买需要兼容客户端验证挑战、取得支出授权，再签名重试。示例 USCC 来自公开静态样例。

字段规则
